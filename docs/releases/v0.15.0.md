# v0.15.0 — Ferramentas locais e análise visual

Data do commit de fechamento: 2026-10-28.

## Resumo

O marco amplia o conjunto de habilidades Rust do agente e adiciona captura de tela com confirmação explícita para análise visual. A versão continua pré-lançamento `0.x`; os testes de código não substituem validação do aplicativo instalado no Windows nem uso com contas reais.

## Adicionado

- Agenda local em SQLite, com criação, listagem, edição, exclusão sujeita a aprovação e importação/exportação iCalendar. O calendário padrão pode ser um arquivo `.ics`, mas abrir esse arquivo não comprova importação por outro aplicativo.
- Habilidades locais para lembretes, leitura/criação de planilhas, busca e proposta de notas de memória, operações limitadas de arquivos e controles de áudio/mídia.
- Integração Discord por webhook cadastrado: segredo no Gerenciador de Credenciais do Windows, teste sem publicar, bloqueio de `@everyone`/`@here`, limite por webhook, prévia e aprovação explícita para envio; a remoção remota exige confirmação.
- Delegação para Codex CLI ou Claude Code já instalados, executada em `git worktree` temporário sob aprovação. O diff é apresentado para revisão e não é aplicado ao projeto original.
- Consulta de recursos de hardware e inventário/download confirmado de modelos GGUF do catálogo, com retomada e verificação SHA-256. O OdeKrai não instala ou inicia um executor GGUF.
- Captura local de tela no Windows, prévia em memória, salvamento separado e envio para análise somente após confirmação e dentro de uma lista explícita de modelos OpenAI e Anthropic.
- Enquadramento JSON-RPC com limites como núcleo técnico; não há transporte MCP, cadastro de servidores, credenciais ou execução encaminhada a servidores.

## Alterado

- Catálogo e telas de provedores, habilidades, Agenda, Computador e configurações foram ampliados; mensagens de falha do agente preservam categorias úteis sem exibir detalhes sensíveis.
- Documentação de pesquisa para integrações Google e Discord foi adicionada. Ela não representa conectores Google ou bot Discord implementados.

## Segurança e limitações

- Políticas, schemas, aprovação, auditoria, kill switch e despacho de habilidades permanecem no Rust. Resultados externos e de ferramentas com conteúdo não confiável não se tornam instruções confiáveis.
- A análise visual está habilitada somente para IDs específicos de modelos OpenAI e Anthropic documentados no código e em `docs/SCREEN-CAPTURE-AND-VISION.md`. A imagem é enviada apenas após a confirmação da pessoa; não é persistida no histórico ou nos logs pelo fluxo descrito.
- A delegação não é um sandbox: as CLIs executam com os privilégios da conta Windows e podem acessar arquivos, rede e credenciais próprias. O uso real das CLIs não foi validado.
- A IA local depende de Ollama ou llama.cpp já instalados e iniciados pelo usuário; ferramentas estão desativadas e não verificadas nesse caminho. A licença e os requisitos dos repositórios GGUF não estão todos verificados.
- Notificações dependem do aplicativo instalado; o calendário externo, Credential Manager, webhooks reais e provedores com contas reais não foram validados neste marco.
- Permanecem pendentes validações visuais/nativas no Windows, incluindo captura física, DPI, múltiplos monitores, janelas, foco, bandeja, instalador, atualização e comportamento do executável instalado.

## Validações

- Passaram nesta preparação: `npm run check:version`, `npm run check:encoding`, `npm run format:check`, `npm run check:debug-command`, `npm run check:tauri-window-commands`, `npm run check:window-api-acl`, `npm run check:release-features`, `node scripts/check-release-artifact.mjs dist`, `npm run build`, `npm test` (136 testes em 37 arquivos) e `cargo fmt --check`.
- `cargo test --lib`: 223 testes passaram. `cargo test` completo e `cargo test --test mock_window --features mock-window-tests` ficaram sem saída durante a compilação e foram interrompidos; esses alvos não estão validados. `cargo clippy --lib -- -D warnings` também não concluiu.
- Não foi executado um workflow CI remoto. Os testes/build locais não comprovam integração com serviços reais, comportamento em instalação Windows nem validação visual.
