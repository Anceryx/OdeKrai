# Distribuição

Não há instalador ou release nesta etapa. Antes de distribuir, configure build Windows reproduzível e CI, valide as dependências e licenças efetivamente empacotadas, faça smoke test da instalação e desinstalação e revise CSP, permissões, chaveiro e banco local.

Um artefato sem assinatura pode gerar alertas do Windows. Não instrua usuários a desativar o Defender. Documente claramente quando a assinatura ainda não estiver disponível. Publicação de release deve ser uma ação manual e explícita.
