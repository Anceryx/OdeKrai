## Problema conhecido: erro de provedor no modo agente

Foi relatado que, com **Modo agente** ligado, provedor OpenAI e modelo `gpt-6-luna`, o erro continua genérico: **“Falha do provedor sem uma categoria mais específica”**. Esse literal é detalhe técnico do fallback em `src-tauri/src/agent.rs::classify_provider_error`; para erros desconhecidos, a função retorna `kind = provider` e uma mensagem segura separada. `src/ui/screens/Conversations.tsx` pode apresentar detalhes técnicos recolhidos. `agent::tests::provider_errors_are_classified_into_safe_actionable_messages` cobre algumas categorias conhecidas e `provider_failure_reaches_the_event_as_specific_safe_error` cobre HTTP 429; nenhum cobre `gpt-6-luna` ou resposta real OpenAI. O relato fica **BLOQUEADO para diagnóstico causal/reprodução**: não há fixture da resposta específica nem prova de chamada ao modelo nesta auditoria. Não inferir se a causa é modelo, API, tool calling ou apresentação do erro sem captura técnica segura.
